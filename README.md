# Hamburguer

1. Qual é a função do HTML na página desenvolvida?

O HTML cria a estrutura e o conteúdo da página: o título, os parágrafos, a imagem, a lista do cardápio e o botão.

2. Onde você utilizou CSS e quais alterações ele realizou?

Usei no arquivo style.css. Ele mudou a cor de fundo da página, as cores e os tamanhos dos textos e a aparência do botão (cor, cantos arredondados e efeito ao passar o mouse). Também adicionei sombras e bordas arredondadas.

3. Onde você utilizou JavaScript e o que acontece quando ele é executado?

Usei no arquivo script.js, na função mostrarPromocao(). Quando o usuário clica no botão, a mensagem da promoção aparece na tela. Se clicar de novo, ela some.

4. Qual é a principal diferença entre CSS e JavaScript?

O CSS cuida da aparência da página (cores, tamanhos e estilo). O JavaScript cuida da interação, ou seja, faz a página reagir quando o usuário faz algo, como clicar em um botão.
